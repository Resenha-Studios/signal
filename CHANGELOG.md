# Changelog

## [2.0.0] (2026-10-19)

### Major Changes & Rebranding
* **Resenha Studios Architecture**: Standardized package naming, unified menu item to `Tools > Resenha > Signal`.
* **Zero Breaking Changes**: Implemented full backward-compatibility layer with `[MovedFrom]` attributes and obsolete proxy classes for `SignalAudioManagerUnity.*`.
* **UI Toolkit AAA Dashboard**: Redesigned dashboard to modern minimal standard with header bar, status badges, and responsive sidebar.
* **5-Language Localization**: Full editor support for English, Portuguese, Spanish, Japanese, and Chinese with real-time language switching.
* **Streamlined UI/UX**: Shifted verbose text into clean tooltips, removed double dashes/slashes, and enhanced error validation.
